# Simabo brand guide

Brand guide v1.1 of [Simabo](https://simabo.org): logo, colors, type, shapes, components, photo, motion and layout.

- Live page: https://valeriorossidigital.github.io/simabo-brand/
- Logo files: `logo/svg/` (vector) and `logo/png/` (transparent, 400–3200px), all in `logo/simabo-logos.zip`.
- The logo is always white on a coloured background (white + shadow on light teal). Never on white, and there is no black/ink logo: never use it.

Static HTML, no build step: edit `index.html` and push to `main`.
